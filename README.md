# Lumen

Demonstration website for a fictional medspa clinic. Browse a care menu and submit a consultation enquiry. Enquiries are stored in this project’s Supabase database.

Demo service and enquiry records were created for this project only.

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000.

Copy `.env.example` to `.env.local` and set `SUPABASE_DB_URL`, `LUMEN_FORM_SECRET`, and `LUMEN_ALLOWED_ORIGINS`.
